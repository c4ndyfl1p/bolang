# BoLang Privacy Policy

_Last updated: 14 November 2026_

BoLang is a browser extension that helps you learn a language by replacing some English words on a web page with their translations. This policy explains what data BoLang handles, why, and what happens to it.

**Summary:** BoLang only reads a page when you click **Translate this page**. It sends that page's visible text to the BoLang server to pick words to translate, and does not store it. BoLang has no accounts, ads, analytics or tracking, and never sells data.

## What BoLang sends, and when

Nothing is sent until you click **Translate this page**. Then the extension sends the following to the BoLang server:

- **The visible text of the current page**, up to 100,000 characters. This is the only page content BoLang reads.
- **Your settings:** the language you're learning and how many nouns, verbs and prepositions to translate.
- **Your invite code**, if you entered one, so the server knows you're allowed to use it.

BoLang does **not** send the page's address (URL), your browsing history, cookies, or anything from pages where you haven't clicked Translate. It doesn't read what you type into forms or text boxes.

## What the server does with it

The BoLang server finds the most frequent nouns, verbs and prepositions in the text and translates them. It sends back only the list of words and their translations.

- **Page text is not stored.** It is processed in memory and discarded as soon as the response is sent. It is never written to disk or to logs.
- **Translations are cached.** Translated words (for example "coffee → kaffe") are kept in memory so the same word doesn't need translating twice. The cache isn't linked to you, and it's cleared whenever the server restarts.
- **Usage limits.** To prevent abuse, the server counts requests per invite code, or per IP address if there is no code. These counters are kept in memory for at most 24 hours.
- **Server logs** record the time of each request, the requester's IP address, the invite code's name, the HTTP status, and how many words were translated. They never contain page text. The hosting provider keeps them only for a short period.

## Third parties

- **Render** (render.com) hosts the BoLang server in its Frankfurt, Germany region (EU). Render processes the requests and logs described above on our behalf.
- **DeepL** (DeepL SE, Germany) translates the words. Only the **individual selected words** (such as "coffee", "in", "brewed") are sent to DeepL, never the page text or anything that identifies you. DeepL handles them under its own [privacy policy](https://www.deepl.com/privacy).

BoLang does not share data with anyone else.

## Data stored on your device

Your settings (target language, amounts, and invite code) are saved in your browser's extension storage on your own computer, so they're remembered next time. They aren't sent anywhere except as described above. Uninstalling the extension deletes them.

## What BoLang doesn't do

- No accounts, sign-up or profiles
- No analytics, tracking or advertising
- No selling or renting of data
- No use of data for anything other than translating the page you asked to translate

## Your choices and rights

- Click **Show original text** to undo the translations on a page at any time.
- Simply don't click Translate on pages you don't want processed.
- BoLang doesn't keep personal data about you beyond the short-lived logs and counters above, so there is normally nothing stored to access or delete. If you have questions or requests under data-protection law (such as the GDPR), contact us below.
